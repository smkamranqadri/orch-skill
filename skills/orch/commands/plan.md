# Orch Plan

Delegate `kis:plan` to an available planner selected from the matrix. Send the task in a brief
file, use the spawn proposal and owner-approval rules in the orch skill, and let the owner answer
the planner in its pane. On the planner notice, have an agent on a different CLI review the plan.
Return the proposed scope, acceptance checks, risks, and review findings to the owner. Do not
implement the plan here.
