# Orch Matrix

Store the user-level matrix at `~/.config/orch/matrix.md`. Keep one table with one row per job:

| Job | Host | Model | Effort | Where | Alternative |
| --- | --- | --- | --- | --- | --- |
| Design, plan | Claude Code | approved model | medium | pane | Codex, approved model, medium |
| Build | Claude Code | approved model | medium | worktree | Codex, approved model, medium |
| Review | Codex | approved model | medium | pane | Claude Code, approved model, medium |
| Explore | Claude Code | approved model | low | pane | Codex, approved model, low |

Replace example values with models the owner has approved. Add a short rules line below the
table for any user-specific selection constraints. Do not store research notes or credentials.
When no matrix exists, make a clearly labeled judgment-based proposal and wait for approval.
